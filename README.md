# Prototyp strony głównej LAKUS

**Wersja robocza projektu – to nie jest oficjalna strona firmy LAKUS Sp. z o.o.** Formularz zgłoszenia niczego nie wysyła, a część danych (m.in. główny numer telefonu i obszar działania) czeka na potwierdzenie.

Podgląd: https://matkuczynski.github.io/lakus-prototyp/

Strona ma znacznik `noindex`, więc nie trafia do wyszukiwarek.

## Zawartość

- `index.html`, `assets/css`, `assets/js` – klikalny prototyp HTML/CSS/JS w świecie wizualnym „Wodomierz”
- `assets/fonts/` – Bricolage Grotesque, Onest i Barlow Condensed na licencji SIL Open Font License 1.1 (teksty licencji w `LICENSES/`)
- `assets/img/` – logo LAKUS i miniatury filmów z kanału YouTube LAKUS

## Aktualizacja

Repo to kopia folderu `prototyp/` z projektu (bez jego README). Podmień pliki, zrób commit i push do `main` – GitHub Pages przebuduje stronę w około minutę.
